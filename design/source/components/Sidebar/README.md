# Sidebar

The desktop navigation for the business app and the admin console. Both use the same white `tz-side`: `surface` with a hairline right edge. The active item is a mint `wash-strong` fill with `ink` text at weight 500 and a `brand` icon, which is the only green in the sidebar. The admin console adds a small `tz-side-tag` reading "Admin" next to the logo, so staff always know which app they are in.

- Spacing follows Kargul Studio's sales CRM: 12px panel padding, 32px items with 8px corners, 16px thin icons, 14px labels at weight 400 in `ink-2`, 11px uppercase group labels in `ink-3`. Hover is the faint `surface-subtle` wash.
- Counts sit in a small white square badge with a `line-control` border (`radius-xs`), right-aligned.
- Collapses to the BottomNav below 1024px for the business app; the admin console collapses to icons.
