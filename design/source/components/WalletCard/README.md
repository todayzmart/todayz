# WalletCard

The points balance on a black `inverse` card, with what it is worth and how to earn more.

- Points in `on-inverse` at `otp` size; the rupee value under it ("Worth ₹42 off your next order").
- Points are credits, not cash: never show a withdraw action.
- Below the card, list recent earnings and redemptions; referral invite sits as a secondary action.
