# shared/api-client

The TypeScript client of the contract (W0-04): `src/http.ts` (hand-written: `configure`,
`request`, `ApiError`, `checkPath`), `src/gen/**` and `src/mocks/handlers.gen.ts` (generated by
`make gen`, git-ignored), `src/mocks/index.ts` (`problemResponse`), the Redocly and orval
scripts in `scripts/`.

Read first: `shared/CLAUDE.md`, `backend/api/README.md`, 04-api.md §1, D-100.

## Rules

- Change the client by changing the contract (`backend/api/paths/<domain>.yaml`) and running
  `make gen`. Never edit `src/gen` or the bundle. `test/regen.test.ts` proves a removed
  operation disappears from the client.
- Every call goes through `request()`. A non-2xx answer throws `ApiError`; switch on `err.code`
  (a registered problem code) and translate it with `problems.<code>`. An answer without problem
  JSON becomes `internal` (5xx) or `bad_request` (4xx), both registered codes; the client never
  invents one.
- `validation_failed` is 422 with `fields` keyed by prefixed path (`body.items[2].quantity`,
  `query.limit`, `path.orderId`, `header.If-Match`). Map `body.*` keys to form fields; the
  prefix is part of the key.
- `ApiError.toJSON()` is `{code, status, requestId}` only: logging or reporting an error never
  carries a problem's `detail`, `fields` or `extensions`.
- Path parameters (D-100 M-3): orval encodes every path parameter (`urlEncodeParameters`), and
  `request()` refuses a built path with a dot segment (`/../`, `/./`, `%2e`), a backslash, a
  tab, CR or LF, or outside `/v1/` and the health paths, with a `TypeError`. That is the last
  wall, not the first: validate ids
  with the generated Zod schemas (`gen/<domain>/<domain>.zod`, `Ulid` is a 26-character
  pattern) before calling, so a bad id is a form error, not a thrown request.
- `request()` sets `Accept: application/json, application/problem+json` only when the caller
  has not set one, so a CSV export or an SSE stream asks for its own type. It resolves by the
  response's `Content-Type`: `application/json` or `+json` is parsed (undefined for 204/205 or
  an empty body), `text/*` is the text (a CSV export), anything else a `Blob`.
- The MSW generator (`scripts/msw.mjs`) writes every string from the contract with
  `JSON.stringify`, defuses `*/` and line breaks in comments and refuses an `operationId` that
  is not an identifier; it never interpolates contract text raw into the generated source.
- Redocly stays in this package (D-100 D5): `make gen` runs `scripts/bundle.mjs` here for the
  backend's bundle, which is allowed because every folder may depend on `shared/`. Nothing in
  this package reads `backend/` on its own: `make gen` passes every path (`TODAYZ_API_ROOT`,
  `TODAYZ_OPENAPI`, `TODAYZ_REDOCLY_CONFIG`, `TODAYZ_PROBLEMS_DIR`), and `scripts/gen.mjs` writes
  the problem-code registry it was given to `src/gen/problems.json` (git-ignored) for the tests.

## Tests

`pnpm --filter @todayz/api-client test` (vitest): `http.test.ts` (the wrapper), `msw.test.ts`
(the generator, including hostile contract text), `generated.test.ts` and `regen.test.ts`
(need `make gen` first; so does the registry test in `http.test.ts`, which skips before
`make gen` and fails under `make check`, where `TODAYZ_CHECK` is set). `make check` runs lint,
typecheck and the tests (`check-contract-client`).
