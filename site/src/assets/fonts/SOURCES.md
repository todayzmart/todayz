# Site font sources

Sora and Manrope are variable fonts distributed by Google Fonts under the SIL Open Font License. The original licenses are kept beside the fonts. These are locally hosted assets, with no browser requests to a font CDN.

- Sora: https://github.com/google/fonts/tree/main/ofl/sora
- Manrope: https://github.com/google/fonts/tree/main/ofl/manrope

Downloaded on 31 Oct 2026 from the upstream TTF sources and converted to WOFF2 with fontTools; no glyph outlines or family names were changed.
