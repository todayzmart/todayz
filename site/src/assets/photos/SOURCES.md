# Site photos: sources

The product photos on the "For every kind of shop" tiles on For retailers (D-260, replaced by D-269). Each is a single product on white, trimmed, padded to a square and saved as 240 × 240 WebP; the page multiplies it onto the tile's pastel tint. CC0 and public-domain files need no credit; this list records where each came from. The customer app's Home category tiles use the same photos at 320 px (`customer/src/home/photos/SOURCES.md`, the `cat-` files).
